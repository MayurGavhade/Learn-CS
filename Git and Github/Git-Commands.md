These are some of the most commonly used Git commands:

1. git init - Initialize a new Git repository 
2. git status - Show the working tree status
3. git clone - Clone a repository into a new directory
4. git add - Add file contents to the index
5. git commit - Record changes to the repository
6. git push - Push changes to the remote repository
7. git pull - Pull changes from the remote repository
8. git branch - List, create, or delete branches
9. git switch - Switch to a different branch
10. git rm - Remove files from the working tree and index
11. git restore - Restore working tree files from the index
12. git merge - Merge changes from one branch into another
