Types of number systems
1. Decimal System
base: 10, from 0 to 9.
2. Binary System
base: 2, just 0 and 1.
3. octal System
base: 8, from 0 to 7.
4. hexadecimal System
base: 16, from 0 to 9. And a to f.

Conversion from One System to Another System.

1. Decimal to base b
-> Keep dividing by base and note the remainders.
-> write the remainders in reverse order.

e.g. Convert (17)10 to base 2.
17 / 2 = 8 remainder 1
8 / 2 = 4 remainder 0
4 / 2 = 2 remainder 0
2 / 2 = 1 remainder 0
1 / 2 = 0 remainder 1

-> The binary representation of 17 is 10001.

2. base b to Decimal
-> Multiply each digit by the base raised to the power of its position, starting from the right.

e.g. Convert (10001)2 to base 10.
10001 = 1 * 2^4 + 0 * 2^3 + 0 * 2^2 + 0 * 2^1 + 1 * 2^0
= 16 + 0 + 0 + 0 + 1
= 17
-> The decimal representation of 10001 is 17.

e.g. Convert (21)8 to base 10.
21 = 2 * 8^1 + 1 * 8^0
= 16 + 1
= 17
-> The decimal representation of 21 is 17.
